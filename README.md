# CityHaven

CityHaven là một trang web giới thiệu về giải pháp đô thị hiện đại.

## Cấu Trúc Dự Án

- `index.html` - Trang chủ của website
- `contact.html` - Trang liên hệ với biểu mẫu liên lạc
- `styles.css` - Stylesheet chung cho toàn bộ website
- `contact.js` - JavaScript xử lý validation và gửi biểu mẫu liên hệ

## Tính Năng Trang Liên Hệ

Trang liên hệ bao gồm:

### Thông Tin Liên Lạc
- Địa chỉ văn phòng
- Số điện thoại liên hệ
- Email
- Giờ làm việc

### Biểu Mẫu Liên Hệ
- Validation form đầy đủ
- Kiểm tra định dạng email và số điện thoại
- Thông báo lỗi chi tiết cho từng trường
- Thông báo thành công khi gửi form
- Responsive design cho mobile và desktop

## Cách Sử Dụng

1. Mở file `index.html` trong trình duyệt web để xem trang chủ
2. Click vào "Liên Hệ" trong menu để truy cập trang liên hệ
3. Điền thông tin vào biểu mẫu và gửi

## Công Nghệ Sử Dụng

- HTML5
- CSS3 (với CSS Variables và Flexbox/Grid)
- Vanilla JavaScript (ES6+)
- Responsive Design
- Form Validation
